# SquadFlow

O **SquadFlow** é um projeto de exploração técnica desenvolvido para consolidar conhecimentos no ecossistema moderno de desenvolvimento Web. Foi o meu primeiro contacto prático com a integração de um frontend reativo em React com uma API robusta em Node.js.

## Objetivos de Aprendizagem
Este repositório serviu como um "sandbox" para testar:
* **React + TypeScript:** Implementação de interfaces com tipagem estática para evitar erros em runtime.
* **Vite:** Utilização de um build tool rápido para otimizar o fluxo de desenvolvimento.
* **Arquitetura Full-stack:** Organização de um projeto com separação clara entre cliente e servidor.

## Tech Stack
* **Frontend:** React.js, TypeScript, Vite, Tailwind CSS (se aplicável).
* **Backend:** Node.js (Pasta `squadflow-api`).

## Estrutura do Repositório
* `/frontend/fut-web`: Aplicação cliente desenvolvida em React.
* `/squadflow-api`: Servidor/API responsável pela lógica de negócio e dados.
